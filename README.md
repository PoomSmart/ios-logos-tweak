# ios-logos-tweak

Cursor Agent Skill: best practices for iOS jailbreak tweaks built with [Theos](https://theos.dev) and Logos.

## Install

Clone into your personal Cursor skills directory:

```bash
git clone <your-repo-url> ~/.cursor/skills/ios-logos-tweak
```

Or symlink this repo to that path.

Cursor loads skills from `~/.cursor/skills/<skill-name>/SKILL.md`.

## Contents

| File | Purpose |
|------|---------|
| [SKILL.md](SKILL.md) | Agent instructions (Logos, Substrate, messaging, ivars) |
| [reference.md](reference.md) | Logos vs manual `MSHook*` reference |

## Usage

Attach or mention **ios-logos-tweak** in Cursor Agent chat when writing or reviewing tweak code (`.x`, `.xm`, hooks, swizzling).
